# Onboarding Readiness Coordinator

An HR operations agent that tracks new-joiner prerequisites and highlights onboarding blockers.

## Workflow

1. Load the approved checklist and start date.
2. Compare requirements with task records.
3. Prioritize overdue, blocking, or unassigned items.
4. Provide a readiness report for HR confirmation.

## Passport Files

The root folder contains `agent.yaml`, `SOUL.md`, and `EXPLAINABILITY.md`.
